# Valentino POS

A lightweight, browser-based point of sale for Valentino. The product catalog, stock, and completed sales are saved in the current browser using local storage. This demo does not process payments or sync data between devices.

## View

- Live site: https://valentinondalila.github.io/pos1/
- GitHub repository: https://github.com/valentinondalila/pos1

GitHub Pages deploys the static site automatically whenever changes are pushed to `main`.

## Run locally

Open `index.html` in a browser. No package installation or build step is needed.

## Notes

- Sample catalog prices use USD and should be replaced with your actual products and currency.
- WhatsApp links need the phone number in international format for WhatsApp to open the right chat. Update the supplied number if `07147756` is incomplete.
- Review the starter store policies against your products and local laws before publishing.
